# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users
Developers, students, and keyboard enthusiasts seeking to improve their typing speed, accuracy, and muscle memory for both natural language text and real-world code (HTML snippets).

## Product Purpose
Provide an ultra-responsive, distraction-free typing trainer and arcade mini-game suite that tracks WPM and accuracy in real-time, stores custom content locally, and runs directly with zero friction.

## Positioning
A lightweight, self-contained typing and code-speed trainer featuring dedicated code typing (HTML practice), dual mini-games (Word Race & Word Shooter), and customizable offline datasets with no cloud account or telemetry required.

## Operating Context
Used during quick 1-to-5 minute warm-up drills, focused practice sessions, or desktop offline drills. Runs locally and can be packaged into a standalone desktop application.

## Capabilities and Constraints
- Real-time WPM, accuracy, and time tracking
- Standard typing mode with random sentences
- HTML snippet mode for developer syntax typing
- Mini-games: Word Race (30s sprint) & Typing Shooter (falling word defense)
- Dynamic in-app content manager with persistent JSON storage
- 3 distinct themes (Obsidian Dark, Cobalt Blue, Nordic Light)
- Local storage for personal best high scores and test counts
- Standalone execution without external server infrastructure

## Brand Commitments
- Name: TypeRush
- Tactile, precise, and distraction-free aesthetic inspired by mechanical keyboard culture and modern developer tooling.

## Product Principles
1. **Typing First**: The text display and typing stage is the hero; chrome and statistics recede when typing begins.
2. **Tactile Feedback**: Immediate, non-punitive visual cues for mistakes, progression, and pacing.
3. **Low Latency**: Instant tab switching, smooth keystroke responsiveness, zero unnecessary layout shifts.
4. **Self-Sovereignty**: All data and custom texts remain on the user's machine with straightforward JSON persistence.
